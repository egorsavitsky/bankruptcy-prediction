# Прогноз банкротства компаний

Сравнение логистической регрессии, случайного леса и CatBoost на финансовых показателях компаний. Всё исследование — в [bankruptcy.ipynb](bankruptcy.ipynb): загрузка, проверка данных, признаки, сравнение моделей и разбор ошибок.

## Данные

[UCI Polish Companies Bankruptcy](https://archive.ics.uci.edu/dataset/365/polish+companies+bankruptcy+data): 64 числовых показателя и метка банкротства. Используется `5year.arff` — 5 910 наблюдений, 410 банкротств. По описанию UCI этот файл соответствует горизонту прогноза один год.

Архив загружается первой ячейкой с данными и сохраняется в `data/raw/`. Данные не включены в репозиторий; версия проверяется по SHA-256.

## Запуск

Проверено на Python 3.13.

```bash
python -m venv .venv
```

Установка библиотек в Windows:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

На Linux/macOS: `.venv/bin/python -m pip install -r requirements.txt`.

Открой `bankruptcy.ipynb` в VS Code или Jupyter, выбери Python из `.venv` и выполни ячейки сверху вниз. Модели обучаются заново, результаты и графики сохранены в ноутбуке.

Если загрузка архива не проходит, скачай [официальный ZIP](https://archive.ics.uci.edu/static/public/365/polish%2Bcompanies%2Bbankruptcy%2Bdata.zip) и сохрани его как `data/raw/polish_companies_bankruptcy.zip`. Отключать проверку HTTPS не требуется.

## Проверка моделей

Точные совпадения исходных признаков группируются, чтобы не пересекать границы train, validation и test. Примерное разбиение — 60/20/20, seed=42. Предобработка выполняется внутри Pipeline. Конфигурации выбираются по Average Precision на трёх групповых фолдах train; validation используется для порога проверки при условных затратах FN:FP=10:1. Test оценивается после фиксации моделей и порогов.

| Модель | Test ROC-AUC | Test Average Precision |
|---|---:|---:|
| Логистическая регрессия | 0,9080 | 0,6779 |
| Случайный лес | 0,9215 | 0,6361 |
| CatBoost | 0,9555 | 0,8201 |

Вариант CatBoost на исходных показателях выбран по train CV. Добавленные признаки и корреляционный отбор не улучшили средний CV AP. При проверке 10% наблюдений по score CatBoost обнаруживает 66 из 82 банкротств на test; precision составляет 55,5%. Это результат одного зафиксированного разбиения.

## Ограничения

Нет идентификаторов компаний и дат публикации отчётности: точные дубликаты разделены по группам, но независимость разных отчётов одной компании и качество на будущем периоде не проверены. Исторические польские данные не подтверждают переносимость на другой рынок. Метка банкротства отличается от банковского дефолта; вероятностный выход отдельно не калибровался.
