# Прогноз банкротства компаний

Исследование финансовых показателей компаний для прогноза банкротства на горизонте одного года. В проекте сравниваются логистическая регрессия, случайный лес и CatBoost, проверяется польза дополнительных признаков и разбираются ошибки моделей.

Код, графики и результаты эксперимента собраны в [bankruptcy.ipynb](bankruptcy.ipynb).

## Данные

Используется [UCI Polish Companies Bankruptcy](https://archive.ics.uci.edu/dataset/365/polish+companies+bankruptcy+data):

- 5 910 наблюдений финансовой отчётности;
- 64 числовых показателя: прибыльность, долговая нагрузка, ликвидность и другие характеристики;
- 410 положительных меток банкротства — около 6,9% выборки.

Для годового горизонта выбран файл `5year.arff`. По описанию UCI цифра в имени обозначает год наблюдения, а не срок прогноза. Файлы с другими горизонтами в эксперимент не включены.

## Подход

- Точные совпадения исходных признаков объединены в группы, которые не пересекают границы train, validation и test. Разбиение — примерно 60/20/20, seed=42.
- Обработка пропусков, ограничение выбросов и масштабирование включены в Pipeline и обучаются внутри фолдов.
- Конфигурации сравниваются по Average Precision на трёх групповых фолдах train. Для CatBoost проверены исходные показатели, дополнительные признаки и сокращённый набор колонок.
- Validation используется для выбора порога дополнительной проверки при условных затратах FN:FP=10:1. Итоговые метрики рассчитаны на test после фиксации моделей и порогов.
- В ноутбуке приведены перестановочная важность признаков, примеры FP/FN и групповые bootstrap-интервалы оценки качества.

## Результаты

Для каждой семьи показана конфигурация, выбранная по train CV.

| Модель | Test ROC-AUC | Test Average Precision |
|---|---:|---:|
| Постоянный прогноз | 0,5000 | 0,0694 |
| Логистическая регрессия | 0,9080 | 0,6779 |
| Случайный лес | 0,9215 | 0,6361 |
| CatBoost | 0,9555 | 0,8201 |

По CV выбран CatBoost на исходных показателях. Дополнительные признаки и корреляционный отбор не улучшили средний AP. Разница между исходными и дополненными признаками мала относительно разброса фолдов.

В 10% наблюдений с наибольшей оценкой риска попало 66 из 82 банкротств на test: recall — 80,5%, precision — 55,5%. Результаты относятся к одному зафиксированному разбиению.

## Воспроизведение

Эксперимент выполнен на Python 3.13. Версии библиотек зафиксированы в `requirements.txt`.

```bash
git clone https://github.com/egorsavitsky/bankruptcy-prediction.git
cd bankruptcy-prediction
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Ноутбук выполняется сверху вниз в VS Code или Jupyter с ядром из `.venv`. Данные скачиваются автоматически в `data/raw/` и проверяются по SHA-256. При недоступности загрузки [официальный архив](https://archive.ics.uci.edu/static/public/365/polish%2Bcompanies%2Bbankruptcy%2Bdata.zip) можно сохранить как `data/raw/polish_companies_bankruptcy.zip`.

## Ограничения

В данных нет идентификаторов компаний и дат публикации отчётности. Группировка устраняет пересечение точных дубликатов, но не гарантирует независимость разных отчётов одной компании. Качество на будущем периоде и переносимость на другой рынок не проверены. Метка банкротства отличается от банковского дефолта, а выход модели отдельно не калибровался как банковская PD.
